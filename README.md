# Foundations of IoT
### Laboratory Experiments | 8051 & STM32

A collection of laboratory experiments exploring microcontroller programming, embedded systems, peripheral interfacing, and hardware-level implementation.

---

## Repository Overview

This repository organizes the Foundations of IoT laboratory work across two microcontroller platforms:

- **8051 Microcontroller** – Embedded C programming, port interfacing, and fundamental microcontroller operations.
- **STM32 Microcontroller** – ARM-based embedded development, GPIO configuration, peripheral interfacing, and HAL-based programming.

Each experiment is maintained in its respective directory with project files, technical documentation, and circuit diagrams.

## Experiment Documentation

Every experiment follows a consistent documentation format containing:

| Section | Description |
|---|---|
| EXP | Experiment identifier |
| DATE | Date of execution |
| NAME OF EXP | Experiment title |
| HARDWARE SETUP / PLATFORM | Board and components used |
| TASK NO | Task reference |
| Circuit Diagram | Hardware connection schematic |
| Core Logic / Pseudocode / Code Base | Implementation details |
| INFERENCE | Observations and conclusion |

Circuit diagrams are stored within their corresponding experiment directories and referenced directly from the README files.
